# ABMAR — Nova homepage

Projeto Next.js para o site institucional da Associação Brasileira de Medicina de Áreas Remotas e Esportes de Aventura.

## Desenvolvimento

`npm install` e `npm run dev`.

## Publicação

Importe este repositório na Vercel com framework Next.js. Antes de conectar `abmar.org.br`, teste a URL temporária e confira DNS/e-mail.
